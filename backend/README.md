# Airline Booking & Operations System

Учебный проект системы бронирования и управления авиарейсами. Полнофункциональная система с разделением ролей для пассажиров и персонала авиакомпании.

## 📋 Описание проекта

Система управления авиарейсами и бронированиями, состоящая из:
- **Backend**: FastAPI (Python) — REST API для всех операций
- **Frontend**: Flutter (Android) — мобильное приложение

### Основные возможности

**Для пассажиров (Passenger):**
- 🔍 Поиск рейсов по маршруту и дате
- ✈️ Бронирование билетов с выбором мест
- 💳 Оплата бронирования (mock-платежи)
- 📱 Check-in и получение посадочного талона
- 📢 Просмотр объявлений о своих рейсах
- 👤 Управление профилем и бронированиями

**Для персонала (Staff/Admin):**
- 🛫 Управление рейсами (создание, редактирование, изменение статуса)
- ✈️ Управление самолётами и их конфигурациями мест
- 🏢 Управление аэропортами
- 📋 Управление бронированиями и платежами
- 📢 Создание и управление объявлениями
- 👥 Управление пользователями

### Основные сущности

- **Flight** — рейс с информацией о маршруте, времени, статусе
- **Booking** — бронирование пассажира с PNR-кодом
- **Ticket** — билет на конкретное место в самолёте
- **Payment** — платёж за бронирование (mock)
- **Airplane** — самолёт с конфигурацией мест
- **Airport** — аэропорт отправления/назначения
- **Announcement** — объявления о рейсах (автоматические и ручные)
- **CheckIn** — регистрация на рейс с получением посадочного талона

**Важно**: Flutter приложение работает **только через REST API**, прямой доступ к базе данных отсутствует.

## 📦 Требования для запуска

### Backend

- **Python** 3.10 или выше
- **uv** (менеджер пакетов Python) или **pip**
- **Docker** (опционально, для контейнеризации)

### Frontend

- **Flutter SDK** 3.0.3 или выше
- **Android Studio** или **VS Code** с Flutter расширениями
- **Android Emulator** или физическое Android устройство

## 🚀 Запуск Backend

### Вариант 1: Локальный запуск (рекомендуется для разработки)

1. **Перейдите в директорию backend:**
   ```bash
   cd backend
   ```

2. **Установите зависимости:**
   
   С помощью `uv`:
   ```bash
   uv sync
   ```
   
   Или с помощью `pip`:
   ```bash
   pip install -e .
   ```

### Вариант 2: Запуск через Docker

2. **Запустите контейнер:**
   ```bash
   docker-compose up
   ```

## 📱 Запуск Flutter приложения

1. **Перейдите в директорию Flutter приложения:**
   ```bash
   cd flutter_airline_app
   ```

2. **Установите зависимости:**
   ```bash
   flutter pub get
   ```

3. **Сгенерируйте код** (для JSON сериализации и роутинга):
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   ```

4. **Проверьте URL backend:**
   
   Откройте `lib/services/api_service.dart` и убедитесь, что:
   ```dart
   static const String baseUrl = 'http://localhost:8000/api/v1';
   ```
   
   **Для Android Emulator**: используйте `http://10.0.2.2:8000/api/v1`
   
   **Для физического устройства**: используйте IP-адрес вашего компьютера, например `http://192.168.1.100:8000/api/v1`

5. **Запустите приложение:**
   ```bash
   flutter run
   ```

   Или выберите устройство и запустите через IDE (Android Studio / VS Code).

- Password: `changethis` (или значение `PASSENGER_PASSWORD`)
- Роль: PASSENGER
