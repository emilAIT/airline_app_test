# Airline App 2026 – AIT Test

This project is a Flutter-based airline booking application developed as part of the AIT Solutions technical test.

---

## 📱 Features
- Flight search
- Flight booking
- Passenger details
- Ticket confirmation
- Simple UI flow for airline booking

---

## 🎥 Demo Video
https://youtu.be/ziyMW9R6ZRo

---

## 🛠 Tech Stack
- Flutter (Frontend)
- Dart
- Backend located in `/backend` folder

---

## ▶️ How to Run the Project

### Frontend (Flutter)
```bash
cd app
flutter pub get
flutter run
```

### Backend (Python)
```bash
cd backend
python -m app
```
