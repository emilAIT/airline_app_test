# Настройка для физических устройств

Если вы запускаете приложение на **физическом Android устройстве**, вам нужно изменить базовый URL API.

## Шаг 1: Узнайте IP адрес вашего компьютера

**Windows:**
1. Откройте командную строку (cmd)
2. Выполните: `ipconfig`
3. Найдите "IPv4 Address" в разделе вашего активного сетевого адаптера (обычно Wi-Fi или Ethernet)
4. Например: `192.168.1.100`

**Mac/Linux:**
```bash
ifconfig
# или
ip addr
```

## Шаг 2: Измените baseUrl в коде

Откройте файл: `frontend/lib/config/api_config.dart`

Измените строку:
```dart
static const String baseUrl = 'http://localhost:8000/api/v1';
```

На (замените `YOUR_IP` на ваш IP адрес):
```dart
static const String baseUrl = 'http://YOUR_IP:8000/api/v1';
```

Например:
```dart
static const String baseUrl = 'http://192.168.1.100:8000/api/v1';
```

## Шаг 3: Убедитесь что backend запущен

Backend должен быть запущен на вашем компьютере:
```bash
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Обратите внимание на `--host 0.0.0.0` - это важно для того, чтобы сервер был доступен с других устройств в сети.

## Шаг 4: Убедитесь что устройство и компьютер в одной сети

Физическое устройство и компьютер должны быть подключены к одной Wi-Fi сети.

## Горячая перезагрузка

После изменения `api_config.dart`, выполните горячую перезагрузку в Flutter:
- Нажмите `r` в терминале где запущен `flutter run`
- Или перезапустите приложение
